## 1. 当前总体目标与阶段

**一句话目标**：完善 QXtrl 项目的“可演进上下文工作流”，引入并集成 HANDOFF 机制，使复杂大项目开发（尤其是架构规划、文档迭代、多轮决策）能在 token 配额限制下，通过多个 agent/session 实现低摩擦、无缝衔接的切换与恢复。同时支持 P0 决策拍板会议的准备工作。

**当前阶段**：
- 规划与过程工具化阶段（非代码实现）。
- 重点：上下文管理 hygiene（AGENTS.md、规划文档体系、handoff、subagent/fork/worktree 实践）。
- 参考：`QXtrl_第一次讨论会决策清单.md` 中的 P0 决策准备；MVP 仍以 Rabi 虚拟闭环为薄切片目标。
- 已完成 P0 讨论会 PPT 的生成与针对性更新，正在演进工作流本身以匹配实际多 agent 使用体验。
